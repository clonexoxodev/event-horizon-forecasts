# Flippe

A forecasting platform for real-world events. Forecast outcomes you understand and earn from accuracy.

## Features

- Real-time prediction markets
- Supabase authentication
- User dashboard with positions tracking
- Market categories (Finance, Politics, Entertainment, Economy, Technology)

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS + shadcn/ui
- Supabase (Auth + Database)
- React Router
- TanStack Query

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
